# میانپور — نسخهٔ ویندوز

نسخهٔ ویندوزِ اپ میانپور — **دقیقاً با همون گرافیک، تم و منطق اپ اندروید**:
حلقهٔ پاور با ضربان، ۵ تم (نیمه‌شب/جنگل/رز/سنگ/ماسه)، فارسی/انگلیسی،
پینگِ واقعیِ بی‌صدا، اتصال هوشمند، بخش اضطراری و کارت‌های مصرف زنده.

## دانلود

از صفحهٔ [Releases](https://github.com/mostafaiekii/mianboor/releases) — فایل `Mianboor-Windows-1.1.0.zip`.

## نصب

1. زیپ رو Extract کنید
2. `Mianboor.exe` رو اجرا کنید
3. ویندوز چون اپ امضای دیجیتال نداره هشدار می‌ده: **More info → Run anyway**

## چطور کار می‌کنه

- ظاهر و تم: پورت دقیق `ui/Theme.kt` و `ui/Widgets.kt` اندروید — همون رنگ‌ها، همون کارت‌ها، همون نوار پایین
- اتصال: یک پروسهٔ `xray.exe` لوکال (پورت‌های `SOCKS 127.0.0.1:10808` و `HTTP 127.0.0.1:10809` — در صورت اشغال پورت آزاد بعدی)
- «پروکسی خودکار ویندوز» مثل v2rayN رجیستری WinINet رو ست می‌کنه و مرورگرها/بیشتر برنامه‌ها فوری رد می‌شن
- **پینگ واقعی**: برای هر کانفیگ یک هستهٔ موقت بالا میاد و از دلِ تونل HTTPS به `generate_204` می‌ره؛ عدد = تونل واقعاً کار می‌کنه، `999` قرمز = TCP بازه ولی تونل مرده — بدون هیچ دکمه‌ای، خودکار و بی‌صدا (عین موتور v2.9.5 اندروید)
- **قرارداد صادقانه**: تا وقتی ترافیک واقعی از دل تونل رد نشه، اپ نمی‌گه «متصل» (عین اندروید v2.9.6)
- **مصرف زنده**: دانلود/آپلود از StatsService خود هسته — عدد واقعیه، نه نمایشی
- اتصال هوشمند = کمترین پینگ واقعی؛ منتخب‌ها با ستاره؛ مرتب‌سازی پینگ/الفبا
- بخش اضطراری: کشف دامنه از CDN (jsDelivr + raw) → seeds عمومی → کش محلی + تست واقعی هر کانفیگ (عین اندروید)
- بستن پنجره اپ رو نمی‌بنده — در تری می‌مونه؛ خروج کامل از منوی تری؛ موقع خروج پروکسی سیستم برمی‌گرده

## افزودن کانفیگ

- لینک مستقیم: `vmess://` / `vless://` (شامل Reality) / `trojan://` / `ss://` — هر خط یکی
- یا آدرس سابسکریپشن (`https://…`)

## تست‌ها (همه سبز)

```bash
npm test                # ۲۹ تست واحد (پارسر/کانفیگ/استور/اضطراری/زیرساخت) — بدون نیاز به هسته
node test/e2e-electron.js   # E2E سیزده‌گام زیر Xvfb با هستهٔ واقعی: سرور Xray لوکال → ورود → پینگ واقعی → اتصال + اثبات ترافیک → مصرف واقعی → خطای صادقانه → تم/زبان/منتخب‌ها
```

## ساخت از سورس (ویندوز یا لینوکس)

```bash
npm install
npm run build:win       # → build/Mianboor-win32-x64/Mianboor.exe
```
